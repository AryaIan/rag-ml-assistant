# Experiment 104: Effect of feature scaling on an RBF SVM

## Setup
Dataset: scikit-learn breast cancer Wisconsin (569 samples, 30 features, 2 classes). Model: SVC with RBF kernel, with and without StandardScaler. Evaluation: stratified 5-fold cross-validation,
shuffled, seed 1234. Scores are mean ± standard deviation across folds, in percentage points.
Run on 2026-09-21 with scikit-learn 1.9.1, Python 3.12.10.

## Results
| preprocessing | accuracy (%) |
|---|---|
| no scaling | 91.9 ± 2.4 |
| StandardScaler | 97.5 ± 0.9 |

## Conclusion
Best accuracy: StandardScaler (97.5 ± 0.9). It beat no scaling by 5.6 points, more than the fold-to-fold standard deviation (0.9). SVMs with an RBF kernel are sensitive to feature scale because the kernel depends on distances between samples.
