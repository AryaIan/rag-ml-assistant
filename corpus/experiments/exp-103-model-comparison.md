# Experiment 103: Model family comparison

## Setup
Dataset: scikit-learn digits (1797 samples, 64 features, 10 classes). Model: five classifiers with default hyperparameters unless noted. Evaluation: stratified 5-fold cross-validation,
shuffled, seed 1234. Scores are mean ± standard deviation across folds, in percentage points.
Run on 2026-09-21 with scikit-learn 1.9.1, Python 3.12.10.

## Results
| model | accuracy (%) | macro F1 (%) |
|---|---|---|
| Logistic regression (C=1, scaled) | 97.2 ± 0.5 | 97.1 ± 0.5 |
| Random forest (100 trees) | 97.7 ± 0.7 | 97.6 ± 0.8 |
| SVM (RBF kernel, scaled) | 98.3 ± 0.3 | 98.3 ± 0.3 |
| k-nearest neighbours (k=5, scaled) | 97.6 ± 0.9 | 97.6 ± 0.9 |
| Decision tree | 85.4 ± 1.1 | 85.3 ± 1.1 |

## Conclusion
Best accuracy: SVM (RBF kernel, scaled) (98.3 ± 0.3). It beat Random forest (100 trees) by 0.7 points, more than the fold-to-fold standard deviation (0.3).
