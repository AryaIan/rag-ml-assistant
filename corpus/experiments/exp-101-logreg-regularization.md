# Experiment 101: Logistic regression regularization strength (C)

## Setup
Dataset: scikit-learn digits (1797 samples, 64 features, 10 classes). Model: StandardScaler + LogisticRegression (max_iter=2000), varying inverse regularization strength C. Evaluation: stratified 5-fold cross-validation,
shuffled, seed 1234. Scores are mean ± standard deviation across folds, in percentage points.
Run on 2026-09-21 with scikit-learn 1.9.1, Python 3.12.10.

## Results
| C | accuracy (%) |
|---|---|
| 0.001 | 90.8 ± 0.8 |
| 0.01 | 94.8 ± 1.0 |
| 0.1 | 96.8 ± 0.7 |
| 1 | 97.2 ± 0.5 |
| 10 | 96.8 ± 0.8 |
| 100 | 96.0 ± 0.9 |

## Conclusion
Best accuracy: C=1 (97.2 ± 0.5). The gap to C=0.1 is 0.3 points, smaller than the fold-to-fold standard deviation (0.5), so the two are not clearly different. Smaller C means stronger regularization.
